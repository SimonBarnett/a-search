# FR-164: SQS visibilityTimeout must exceed worker Lambda timeout

**Repo:** SimonBarnett/a-search
**Phase:** 3b - AWS installable gap pass 2
**Shape:** service (unchanged)

## Goal
Worker timeout and queue visibility are both 60s. AWS guidance: visibility > function timeout to avoid duplicate receives on timeout. Set visibility to timeout + buffer (e.g. 6x or +30s) consistently.

## Decision (LOCKED)

- Shared constants in `cdk/lib/a-search-stack.js`:
  - `WORKER_LAMBDA_TIMEOUT_SEC = 60`
  - `WORKER_QUEUE_VISIBILITY_TIMEOUT_SEC = WORKER_LAMBDA_TIMEOUT_SEC * 6` (360)
- Every enabled worker queue uses that visibility; every worker Lambda uses that timeout
- Business/provider logic timeouts unchanged (OOS)
- Pin: `tests/fr164-sqs-visibility-timeout.test.js` (source + in-process synth)

## Deliverables
- CDK change + pin asserting visibility > timeout for worker queues

## Testable
- Synth + pin

## Out of scope
- Changing business logic timeouts for providers
