# FR-2230: docs markdown UTF-8 without BOM (beyond docs/mrb)

**Repo:** SimonBarnett/a-search
**Issue:** #2230
**Status:** Decision LOCKED

## Goal
Extend the FR-1410 no-BOM gate from `docs/mrb/` to every markdown file under
`docs/` (recursive), and strip existing BOMs on docs-root tips.

## Decision (LOCKED)

- Gate: `tests/fr2230-docs-no-bom.test.js` walks `docs/` recursively and fails
  if any `*.md` starts with EF BB BF.
- FR-1410 / `tests/fr1410-docs-mrb-no-bom.test.js` remains as the narrower pin.
- Writers: prefer `UTF8Encoding(false)` / `Path.write_text(..., encoding='utf-8')`;
  never WinPS `Set-Content -Encoding utf8` for docs markdown.
- Scope includes `docs/*.md` at repo docs root (e.g. `endpoint-search.md`,
  legacy `mrb-*.md`) and `docs/fr/`, `docs/mrb/`, mocks, etc.

## Testable

- Recursive inventory of `docs/**/*.md` has zero UTF-8 BOMs
- Named survivors from the #2230 intake scan are BOM-free after strip

## Out of scope

- Non-markdown docs assets
- Rewriting historical git blobs (working tree + gate only)
