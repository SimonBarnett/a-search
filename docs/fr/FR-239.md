# FR-239: Per-shop GBP 20 monthly Stripe subscription gates shop live status

**Repo:** SimonBarnett/a-search
**Phase:** 5e - Merchant shops
**Issue:** #1353
**Status:** Decision LOCKED

## Goal
Each merchant shop is a GBP 20/month Stripe subscription. The shop stays
`pending_payment` until a webhook-confirmed active subscription; then it becomes
`live` and FR-240 may queue the parts import. Distinct from widget Upgrade
(`widget_upgrade`, GBP 10/host) and never `partner_monthly`.

## Decision (LOCKED)

- One Stripe **Customer** per merchant (`Shops.StripeCustomerId`); one
  **Subscription** per shop (`StripeSubscriptionId` + `SubscriptionStatus`).
- Price: `SHOP_MONTHLY_PRICE_ID` (GBP 20.00/month, VAT inclusive,
  `tax_behavior=inclusive`). No free trial (`trial_period_days` unset).
- Metadata `aSearchProduct=merchant_shop` on Checkout Session and subscription.
- HTTP (JWT merchant, own shop):
  - `POST /merchant/shops/{shopId}/subscribe` -> `{ checkoutUrl }` when status
    is `pending_payment` or `suspended(payment)`.
  - `POST /merchant/shops/{shopId}/cancel` -> `cancel_at_period_end=true`.
- Shared webhook `POST /webhooks/stripe` (signature via `STRIPE_WEBHOOK_SECRET`;
  idempotent by `event.id` in `StripeEvents`; production database `a_search`
  deletes rows older than 30 days, sandbox persists without that purge):
  | Stripe status / event | Shop transition |
  |---|---|
  | `active`, `trialing` | -> `live` (+ FR-240 `onShopLive`; download paid only when `active`) |
  | `past_due` | stay `live` (grace; no download) |
  | `unpaid`, `incomplete_expired`, `paused` | -> `suspended(payment)` |
  | `customer.subscription.deleted` / `canceled` | -> `cancelled` |
- Invoice events (`invoice.paid` / `payment_failed` / `marked_uncollectible` /
  `finalized`) upsert `ShopInvoices` for FR-241 unpaid-period counting.
- `widget_upgrade` webhooks never touch Shops.
- Modules: `shared/shops/subscribe.js`, `stripeEvents.js`, `shopInvoices.js`;
  entry `stripeWebhook.js` + merchant subscribe/cancel handlers.
- Migration: `db/migrations/017_ShopInvoices_StripeEvents.sql` (a_search only;
  FR-251 madeiradb read-only).
