# FR-3790: Keep the shared CDK synth cache out of the batch sweep

**Repo:** SimonBarnett/a-search
**Issue:** #3790
**Status:** Decision LOCKED

## Decision

`tests/helpers/cdkOutCleanup.js` `isCdkOutStar` matches named and private
`cdk.out-*` dirs. It does not match `cdk.out-shared-*`. Sweep and
register-exit cleanup therefore leave the FR #3764 shared synth cache in
place across `scripts/run-tests.js` batches.

Named `cdk.out-fr*` and private `cdk.out-<pid>-<seq>` dirs are still removed.
Plain `cdk.out` stays. `A_SEARCH_KEEP_CDK_OUT=1` still skips the whole sweep.
