# FR #5318

GitHub: https://github.com/SimonBarnett/a-search/issues/5318

## Goal

When the CJ worker gets one product, it writes exactly one IN file for that search.

## Deliverables

- Worker pin: inject `searchCj` to return one product.
- No live CJ call. No token values.

## Testable

- `/IN/` put count is 1 and the key ends with `-cj.json`.
- `_search-done/{searchid}/cj.json` is serviced with products 1.
- The existing zero-product CJ case still writes no IN file.
