# FR-204: Agent site pass site.md and seed top10.json

**Repo:** SimonBarnett/a-search
**Phase:** 5 - ComponentsPiece
**Shape:** service (unchanged)
**Issue:** #1192

## Goal
First agent pass on customer without site.md writes affiliate skillbook into site.md and seeds top10.json.

## Decision (LOCKED)

- Entry: `shared/widgets/agentSitePass.js` (`runSitePass` / `onTreeEvent`).
- Trigger: `host_created` or `widget_created` when `site.md` is missing (also direct `site_pass`). Other events are ignored.
- Agent CWD: `{root}/{env}/x/{customerNumber}/` via `widgetPath.hostDir` (FR-233).
- Writes: `site.md` (affiliate skillbook, host + customerNumber + env, no secrets) and seed `top10.json` (`{ parts: [], updatedAt, seededBy }`) when absent.
- Idempotent: an existing `site.md` is never regenerated on a duplicate event; if `top10.json` is still missing it may be seeded.
- Fail-when: pass completes without `site.md`, or `site.md` contains secret-shaped needles (`password=`, `api_key=`, `Bearer`, private keys).
- URI maintain loop is out of scope (FR-205+).

## Deliverables
- Agent entry for site pass
- site.md template without secrets
- empty or seed top10.json

- Fail-when: skips site.md
