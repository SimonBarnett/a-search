# FR-3764: Share one CDK synth output across tests

**Repo:** SimonBarnett/a-search
**Issue:** #3764
**Status:** Decision LOCKED

## Goal

Cut full `npm test` wall time on whiterabbit (was ~60-65 min with ~45
synth files each writing ~852 MB). Tests that need a default `ASearchStack`
synth share one `cdk.out-shared-*` directory: synth once, reuse read-only.

## Decision (LOCKED)

- `tests/helpers/runCdkSynth.js`: `sharedSynthOutDir` + `synthArtifactReady`.
- `runCdkSynth(root)` reuses the shared out dir when
  `ASearchStack.template.json` is present unless `opts.fresh` or `opts.outDir`.
- `ensureDefaultStackSynth(root)` for in-process default-stack pins (same cache).
- FR #3462 private dirs remain via `allocateSynthOutDir` / `opts.fresh`.
- Custom-context synths (corsOrigins, stage=dev, throttle, tags) keep private dirs.

## Testable

- `tests/fr3764-shared-synth-cache.test.js`
- Existing FR-3462 uniqueness pins stay green.

## Out of scope

- Changing Lambda asset staging layout itself (reuse skips re-stage by not
  re-synthing).
- Guaranteeing a wall-clock number on every seat (CI concurrency and disk vary).
