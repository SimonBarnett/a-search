# FR-036: CDK queues + worker Lambdas for enabled shortlist

## Goal
Every registry source with `enabled.live` or `enabled.sandbox` true gets
live and sandbox queues plus an SQS-triggered worker Lambda (amazon pattern).

## Deliverables
- Queues named `a-search-{id}-{live|sandbox}` for amazon, ebay, rakuten, cj,
  awin, impact (current enabled set)
- Worker Lambda per source (or per source×env if env must be fixed like
  maintainer) subscribed to the matching queue(s)
- Entry env receives all resolved queue URLs; grants SendMessage
- Outputs for queue URLs

## Testable
- Synth template contains queue names for each enabled id × env
- Event source mapping / queue grant present for worker functions
- Fail-when: only amazon queues exist after synth

## Out of scope
- Disabled shortlist providers; implementing Browse/GraphQL clients (FR-039+)
