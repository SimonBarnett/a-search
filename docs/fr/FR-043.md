# FR-043: Awin MSSQL queryParts SqlClient SELECT

## Goal
Awin local worker default `queryParts` runs a parameterized SELECT against
`dbo.Parts` for the request env/search text instead of always returning `[]`.

## Deliverables
- SqlClient (or `mssql` package) module with injectable connection factory
- Query filters: Source='awin', Env=@env, text match on Title/Description per
  `q` / `searchterms`
- writeResults after normalize (align with amazon worker path)
- `.env.example` connection pieces (server/database/user — no password in git)

## Testable
- Mock connection returns rows → products normalized; empty → products []
- No connection config → clear error (not silent [])
- Fail-when: defaultQueryParts unconditionally returns [] with no SQL module

## Out of scope
- Feed ingest (maintainer owns MERGE)
