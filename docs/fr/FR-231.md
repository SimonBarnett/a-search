# FR-231: Reject OAuth login when no email phone or contact

**Repo:** SimonBarnett/a-search
**Phase:** 5 - ComponentsPiece
**Shape:** service (unchanged; login is delivery)
**Issue:** #1241
**Status:** Decision LOCKED

## Goal
Fail closed when provider profile lacks email, phone, and contact; show error; do not mint identity.

## Decision (LOCKED)

- OAuth completion goes through `shared/auth/oauthCallback.js` (`completeOAuthLogin`)
  after the pluggable adapter `exchange` (FR-226/227).
- HTTP surface: `POST /auth/oauth/callback` (entry + CDK). Body:
  `{ provider, code?, profile?, intent?, role? }`.
- Missing email|phone|contact => `AuthContactError` / `contact_required`;
  response **403** with AL3 copy:
  - `message`: "Provider returned no contact"
  - `al`: `AL3`
  - detail matches `docs/mocks/components-piece-auth/error.html`
- On that reject path, **`createIdentityRow` is never called** -- no Users/Partner
  (a-search DB) row is minted. madeiradb stays read-only (FR-251).
- Happy path: injectable `createIdentityRow(claims)` then `createSharedSession`
  (FR-229). Live OAuth token exchange remains out of scope (fixture adapters).

## Deliverables
- Guard in OAuth callback (`completeOAuthLogin` + HTTP route)
- Error copy for user (AL3)
- Pin: `tests/fr231-oauth-contact-reject.test.js`

## Testable
- Fixture empty contact => rejected
- No Users/Partner row created (`createIdentityRow` call count 0)

## Out of scope
- Account merge UX for later
- Live OAuth app credentials / real token exchange
