# FR-049: Local-provider onboarding agent scaffold

## Goal
Each **local** registry source gets an onboarding agent CWD + scheduled runner
contract: run until work is drained, then self-exit (no forever idle loop).

## Deliverables
- Layout under `providers/local/<id>/onboarding/`:
  - `AGENTS.md` + `.grok/skills/a-search-<id>-onboarding/SKILL.md` (CAST IRON harvest)
  - `src/run.js` exporting `runOnce(deps) -> { processed, remaining, signups[] }`
  - `.env.example`
- Shared orchestrator helper in `shared/onboarding/drain.js`: loop `runOnce`
  until `remaining===0` or max-iterations safety cap; then exit 0
- Docs: `docs/onboarding-agents.md` — schedule, self-close, signup feed
- Registry or checklist listing which local ids require onboarding agents
- Scaffold for every **enabled** local id at minimum (awin, impact); disabled
  locals get stub folder OR explicit defer note in docs

## Testable
- Layout test for awin + impact onboarding paths + harvest needles
- `drain` unit test: three runOnce then remaining 0 → stops; cap prevents infinite loop
- Fail-when: no onboarding CWD for enabled local sources

## Out of scope
- Live Awin API join logic (FR-050); daily email HTML (FR-052)
