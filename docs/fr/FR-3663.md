**Issue:** #3663
**Also lands:** #3462 / PR #3496 (per-synth `--output`)

## Decision (LOCKED)

- `tests/fr2021-ci-queue-starvation.test.js` matches
  `timeout-minutes:[^\n]*\b180\b` so the FR-2611 / #3133 expression
  `timeout-minutes: ${{ needs.classify.outputs.heavy == 'true' && 180 || 5 }}`
  stays green.
- `tests/helpers/runCdkSynth.js` default timeout is `600_000` ms
  (`DEFAULT_SYNTH_TIMEOUT_MS`).
- On timeout, kill the whole process tree (`taskkill /T` on Windows;
  process-group `SIGKILL` on Unix). Never leave an orphan `cdk` holding
  a `cdk.out` lock.
- Each `runCdkSynth` call still uses a private `--output` directory
  (`cdk.out-<pid>-<seq>`, FR #3462).
