# FR-246: Ecwid shop connect via Ecwid app OAuth

**Repo:** SimonBarnett/a-search
**Phase:** 5e - Merchant shops
**Issue:** #1360
**Status:** Decision LOCKED

## Goal

Install the a-search Ecwid (Lightspeed E-Series) app on a merchant store via
OAuth, vault the non-expiring secret access token, and let FR-240 import
catalogue into `a_search.dbo.Parts`. Merchant source.

## Decision (LOCKED)

Simon 14:12 / 15:27 BST (issue updates win).

- Auth: Ecwid external app OAuth. Authorize
  `https://my.ecwid.com/api/oauth/authorize` with scopes
  `read_store_profile read_catalog`. Callback
  `{api}/merchant/shops/callback/ecwid` receives `code` **and `store_id`**
  (required since 2025-09).
- Token exchange: **POST** (never GET)
  `https://my.ecwid.com/api/oauth/token/{store_id}` with
  `application/x-www-form-urlencoded` body
  (`client_id`, `client_secret`, `code`, `redirect_uri`,
  `grant_type=authorization_code`). Secrets never in query string.
- Response `access_token` (`secret_...`) is **non-expiring** while installed;
  ignore `public_token`. Vault pointer on Shop; `providerShopId = store_id`.
- Uninstall: `application.uninstalled` -> `POST /webhooks/shop/ecwid`. Verify
  `X-Ecwid-Webhook-Signature` =
  Base64(HMAC-SHA256(client_secret, `{eventCreated}.{eventId}`)). Then
  `suspended(uninstalled)` + cancel subscription stub (FR-239).
- Provider `providers/local/ecwid/` stay-dark until app creds exist.
  Catalogue: `GET .../api/v3/{storeId}/products?enabled=true&limit=100&offset=N`
  with Bearer secret token; honour 429 + `Retry-After`.
  Parts: `Source=ecwid`, `FeedKey=shopId`, `MerchantProductId=product id`.
- madeiradb read-only (FR-251). All SQL in `a_search` / `a_search_sandbox`.
