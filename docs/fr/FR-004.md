# FR-004: Implement JWT Bearer verify extracting userId claim

## Goal
Verify login JWT and read `userId`.

## Deliverables
- `entry/src/auth/jwt.js` verify → `{ userId }`
- Env: JWT_ISSUER, JWT_AUDIENCE, JWT_JWKS_URL and/or JWT_SECRET
- Reject missing Authorization, bad signature, expired, missing userId claim

## Testable
- Fixture token valid → userId
- Missing token → unauthorized
- Missing userId claim → missing_user_id_claim
- Module never trusts body userId
