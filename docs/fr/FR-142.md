# FR-142: SQS dead-letter queues for each enabled worker queue

**Repo:** SimonBarnett/a-search  
**Phase:** 3 - AWS installable release  
**Shape:** service (unchanged)

## Goal
Attach DLQs to live/sandbox worker queues so poison messages do not loop forever.

## Decision (LOCKED)

- For every enabled worker queue (`a-search-{sourceId}-{live|sandbox}`), create a sibling DLQ named `{queueName}-dlq`
- Primary queue `deadLetterQueue: { queue: dlq, maxReceiveCount: 3 }` (CDK emits `RedrivePolicy`)
- DLQ retention 14 days; DLQ has no further redrive
- Optional stack outputs: `{Pascal}{Live|Sandbox}DeadLetterQueueUrl`
- Pin: `tests/fr142-sqs-dlq.test.js` (source + in-process synth)
- Alarms / DLQ depth metrics stay FR-143
