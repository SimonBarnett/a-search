# FR #5323

GitHub: https://github.com/SimonBarnett/a-search/issues/5323

## Goal

`docs/release-checklist.md` stops requiring every Phase-2 id to stay `enabled=false`.

## Deliverables

- Replace that checkbox with the hold ids that are false on purpose: bol, aliexpress, avantlink, flexoffers, admitad.
- Name squarespace, magento, ecwid, and bigcommerce as later merchant connects that stay false, not as a failure of the enabled set.
- Do not flip registry flags.

## Testable

- The checklist no longer says all Phase-2 providers remain `enabled=false`.
- A pin fails if the hold ids above are not named, and fails if amazon or wix is listed as stay-dark.
