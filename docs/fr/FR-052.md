# FR-052: Daily report signup contract (clubscan parity)

## Goal
Define and implement the signup data feed that onboarding agents provide for
the daily report currently produced by madeira-awin-clubscan.

## Deliverables
- `docs/daily-report-signups.md` mapping clubscan report sections
  (new merchants table, totals, last-24h sales pointer) to a-search emitters
- Persist signup events to MSSQL table or S3 JSON
  `{env}/_reports/{source}/{yyyy-MM-dd}/signups.json` (choose one LOCKED in PR)
- Shared reader used by report job (email may remain UNKNOWN / external)
- Link legacy README:
  https://github.com/SimonBarnett/AWS/tree/main/Lambdas/madeira-awin-clubscan

## Testable
- Contract test: signup object has required fields; writer round-trip
- Docs contain clubscan URL + field table
- Fail-when: onboarding has no documented report feed

## Out of scope
- Pixel-perfect HTML email clone of clubscan (may stay in AWS Lambda until cutover)
