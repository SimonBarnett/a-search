# FR-236: Shopify shop connect via OAuth app install (offline token)

**Repo:** SimonBarnett/a-search
**Phase:** 5e - Merchant shops
**Issue:** #1350
**Status:** Decision LOCKED

## Goal
Merchant clicks Add shop -> Shopify, approves the unlisted/custom app, a-search
stores an offline Admin API token (vault pointer on the Shop row). No pasted keys.

## Decision (LOCKED)

- Provider adapter: `shared/shops/adapters/shopify.js` registered as `shopify`.
- `POST /merchant/shops/connect { provider:"shopify", shopDomain }` validates
  `^[a-z0-9][a-z0-9-]*\.myshopify\.com$`, stores FR-216 nonce, returns
  `https://{shop}/admin/oauth/authorize?client_id&scope=read_products,read_inventory&redirect_uri&state`.
- `GET|POST /merchant/shops/callback/shopify` verifies query HMAC (app secret),
  consumes nonce, exchanges `code` for offline `access_token`, reads shop info,
  vault-puts token at `vault:shopify:{providerShopId}`, inserts Shop
  `pending_payment` (credentialsSecretRef only). Redirects to Subscribe URL.
- Bad hmac / expired state / non-myshopify domain => **400**, no Shop row.
- Token never appears in redirect URL, response body, or logs.
- `POST /webhooks/shop/shopify` (HMAC base64 of raw body):
  - `app/uninstalled` => Shop `suspended` reason `uninstalled` + cancel
    subscription stub (FR-239)
  - `customers/data_request` / `customers/redact` => **200** (no customer PII)
  - `shop/redact` => delete Shop row + vault entry
- App client id/secret: Secrets Manager `a-search/{env}/providers/shopify/app`
  (injectable in tests). Separate app per env.
- Catalogue: `providers/local/shopify/src/catalog.js` accepts per-call
  `{ shopDomain, accessToken }` overrides; env remains selftest fallback.
- Unlisted/custom-distribution app; Stripe billing (FR-239), not Shopify Billing.
- madeiradb read-only (FR-251). Shops in a_search (FR-216 migration).
