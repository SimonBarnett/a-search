# FR-1344: Chrome Extension (Club TXT gate + top bar + widget APIs)

**Repo:** SimonBarnett/a-search
**Phase:** 5 - ComponentsPiece
**Issue:** #1344
**Status:** Decision LOCKED (MVP landing)

## Goal
Chrome MV3 extension enabled only when Club TXT is present; top bar + widget
mutate APIs; GUID-based widgets (FR-232 prelude already on `POST /widgets`).

## Decision (LOCKED)

- Folder: `extension/` (Manifest V3). Content script on `<all_urls>`; inert until
  `GET /ext/status` returns `enabled:true` with non-null `clubId` (Simon 14:35).
- JWT only in `chrome.storage.session` (`extension/background.js`). Never
  `localStorage` / `sessionStorage` / `document.cookie` assignment.
- Top bar: Shadow DOM (~36px). Logged-out shell shows Login.
- Edit affordance: one button per `.a-search-widget[data-widget-guid]`.
- Server handlers (win over FR-208 501 stubs):
  - `GET /account/commission` -> `{ unclaimedMinor, currency }`
  - `POST /account/upgrade` -> Checkout URL stub (live Stripe later / #1345)
  - `PATCH /widgets/{widgetGuid}` -> layout; `fullscreen` => **402**
    `upgrade_required` unless host upgraded
  - `POST /widgets/{widgetGuid}/feedback` -> append context|remove; `other`
    without text => **400**
- madeiradb read-only (FR-251). Commission/upgrade stores are injectable /
  a-search-side.
- FR-234 stats routes stay 501 until #1348.
