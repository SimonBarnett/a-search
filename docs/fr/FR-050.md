# FR-050: Awin onboarding agent (scheduled drain + signup rows)

## Goal
Port the clubscan onboarding responsibility into a-search’s awin onboarding
agent: discover newly joined programmes, create/link local users, emit signup
rows for the daily report, run on a schedule until drained, then exit.

## Deliverables
- `providers/local/awin/onboarding/src/` implementing joined-programme sync
  (injectable Awin HTTP + MSSQL), idempotent user create
- Signup row schema fields aligned with clubscan daily report needs:
  company_name, email, website, logoUrl, primarySector, description, user_id,
  advertiserId, env, onboardedAt
- EventBridge (or CDK cron) target invoking drain runner with `A_SEARCH_ENV`
- Skillbook playbook referencing legacy
  `SimonBarnett/AWS/Lambdas/madeira-awin-clubscan/routes/onboarding.js`
- Sandbox mode flag generating safe test signups without live Awin side effects

## Testable
- Fixture programmes → signup rows; already-known email skipped
- drain exits when no new programmes
- Fail-when: no signup emission or runner never exits

## Out of scope
- Full HTML email send (FR-052 may consume signup JSON); payments ingest
