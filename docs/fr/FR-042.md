# FR-042: Shared product result schema + normalizer contract

## Goal
Lock a minimal product object shape written into results JSON so Club Madeira
callers can merge multi-source files without per-provider forks.

## Deliverables
- `docs/result-schema.md` with required fields (id, title, url, price,
  currency, imageUrl, source, raw optional)
- `worker/lib/normalizeProduct.js` helper used by amazon (refactor) and new
  clients
- Hostile pin test that amazon normalize output satisfies schema

## Testable
- Schema doc present; unit tests reject missing id/title/source
- amazon fixture normalize passes schema assert
- Fail-when: providers invent incompatible top-level keys with no shared doc

## Out of scope
- Grok relevance ranking
