# FR-222: Partner and club Stripe payouts optional until payout

**Repo:** SimonBarnett/a-search
**Phase:** 5 - ComponentsPiece
**Shape:** service (unchanged; wizard/pages are delivery)

## Goal
Partners/clubs can register and run without Stripe payout account; Connect/payout setup only when they request payout.

## Deliverables
- Payout-optional flag on partner/club
- Start-payout flow creates Stripe payout account when requested
- Docs

## Testable
- Register without Stripe payout id succeeds
- Payout request without account => setup path

## Out of scope
- Merchant subscription (FR-217)
