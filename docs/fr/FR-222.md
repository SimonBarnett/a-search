# FR-222: Partner and club Stripe payouts optional until payout

**Repo:** SimonBarnett/a-search
**Phase:** 5 - ComponentsPiece
**Shape:** service (unchanged; wizard/pages are delivery)
**Issue:** #1227

## Goal
Partners/clubs can register and run without a Stripe payout account;
Connect/payout setup runs only when they request payout.

## Decision (LOCKED)

- Partner and club tenants carry `payoutOptional: true` and may have
  `stripePayoutAccountId: null` after registration. Forced Connect at register
  is a fail (CP17).
- `POST /account/payouts` (JWT): if no Connect account, returns
  `{ setupRequired: true, setupPath: "/account/stripe/link" }` -- not a hard
  failure that blocks the tenant.
- `POST /account/stripe/link` (JWT): start payout setup via injectable Stripe
  Connect account + account-link creators (no secret keys in git; account id
  only stored). Returns `setupUrl` for the hosted onboarding flow.
- Once `stripePayoutAccountId` is set, `POST /account/payouts` returns
  `{ ok: true, setupRequired: false, stripePayoutAccountId }`.
- Docs/mocks already state payouts are optional until requested.
- Out of scope: merchant subscription (FR-217); live Stripe network calls in CI.

## Deliverables
- Payout-optional tenant model (`shared/partners/payoutOptional.js`)
- Start-payout + setup routes (entry + CDK)
- Decision LOCKED doc + pins

## Testable
- Register without Stripe payout id succeeds
- Payout request without account => setup path

## Out of scope
