# FR-235: Merchant Shops registry (#1349)

**Repo:** SimonBarnett/a-search
**Phase:** 5e - Merchant shops
**Issue:** #1349
**Status:** Decision LOCKED

## Goal
Many shops per merchant with status machine, vault credential pointers, and
JWT list/delete APIs. Connect orchestration remains FR-216; Stripe FR-239;
provider OAuth FR-236..238 / 242..246.

## Decision (LOCKED)

- Shops live in `a_search` / `a_search_sandbox` only (`db/migrations/010_Shops.sql`
  + `011_ShopStatusLog.sql`). madeiradb is read-only (FR-251).
- Unique `(env, provider, providerShopId)`. Same merchant reconnect refreshes
  credentials (one row). Another merchant -> **409** `shop_already_connected`.
- Status machine: `pending_payment` | `live` | `suspended` | `cancelled` with
  audit rows in `ShopStatusLog`. `cancelled` is terminal (new connect = new row).
  `pending_payment` may go to `suspended` (provider uninstall before pay, FR-236).
- Credentials: Secrets Manager pointer only (`a-search/{env}/shops/{shopId}`).
  Never in API JSON, logs, SQS, or S3. Logger redaction covers
  `token|secret|key|password` (`shared/shops/redactLog.js`).
- Provider enum: `shopify|wix|woocommerce|squarespace|magento|bigcommerce|ecwid`
  (no `prestashop`).
- HTTP (JWT merchant, own shops):
  - `GET /merchant/shops`
  - `DELETE /merchant/shops/{shopId}` (cancel subscription at period end + mark
    cancelled; Stripe wire is FR-239 injectable)
- Module: `shared/shops/` (`registry`, `status`, `vault`, `redactLog`).

## Testable
`tests/merchant-shops.test.js`

## Out of scope
Provider OAuth (FR-236+), Stripe Checkout (FR-239), catalogue sync (FR-240)
