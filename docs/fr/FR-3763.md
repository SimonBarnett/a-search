# FR-3763: Delete named cdk.out-* after synth tests

## Decision

LOCKED 2026-10-17

## Intent

Follow-up to #3663 / #3743. Private `cdk.out-<pid>-<seq>` cleanup was not
enough: in-process `cdk.App({ outdir: 'cdk.out-fr142' })` tests leave named
dirs (~14 GB per full run) on self-hosted runners.

## Acceptance

- Every `cdk.out-*` directory a test creates is removed after the test or at
  suite end (including named `cdk.out-fr*`).
- Plain `cdk.out` (no hyphen suffix) is left alone.
- `cdk.out-shared-*` is left alone (FR #3790 / FR #3764 shared synth cache).
- `A_SEARCH_KEEP_CDK_OUT=1` skips cleanup.
- A full `npm test` / `scripts/run-tests.js` run leaves no `cdk.out-*` in the
  workspace root.

## Implementation

- `tests/helpers/cdkOutCleanup.js` — `registerCdkOutDir`, `sweepCdkOutDirs`
- `tests/helpers/runCdkSynth.js` — registers every outDir (named + private)
- `scripts/run-tests.js` — sweeps after each batch and at exit
- Pin: `tests/fr3763-named-cdk-out-cleanup.test.js`
