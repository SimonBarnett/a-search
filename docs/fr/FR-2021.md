# FR-2021: CI test-and-synth queue starvation

**Repo:** SimonBarnett/a-search
**Phase:** 3 - AWS installable release / CI hardiness
**Shape:** service (unchanged)

## Goal
Stop docs/harvest tip PRs from starving the GitHub Actions queue behind 180m CDK synth jobs so MRB merges are not BLOCKED for 20+ minutes on a missing `test-and-synth` check.

## Decision (LOCKED)

- Keep job id `test-and-synth` (ruleset `required-ci-3948` context must not rename).
- Add workflow `concurrency` per PR/ref with `cancel-in-progress: true`.
- Path-aware `npm run synth`: skip when the PR diff touches only docs/skills/tests (and similar); always synth on `push` to `main`; always synth when cdk/providers/entry/maintainer/shared/components-piece/package.json/lock/scripts/stage|smoke/cdk.json change.
- `npm test` still runs on every PR (in-process synth pins remain).
- MRB when still BLOCKED on a long queue with local green unit tests: document admin-merge / file backlog intake (existing harvest lesson); prefer waiting for this path-aware gate after land.

## Deliverables

- `.github/workflows/ci.yml` concurrency + path-aware Synth step
- `docs/fr/FR-2021.md` Decision LOCKED
- `tests/fr2021-ci-queue-starvation.test.js`
- harvest-agent-skills lesson bullet

## Testable

- Pin asserts concurrency group, cancel-in-progress, need_synth step, job id `test-and-synth`, FR-139 needles still present
- Local `node --test tests/fr2021-ci-queue-starvation.test.js` green

## Out of scope

- Changing ruleset required check names
- Splitting into separate required jobs (would need ruleset update)
- Cancelling unrelated open PRs' runs from a worker seat
