# FR-006: Fan-out enqueue one SQS message per enabled registry source

## Goal
SendMessage per enabled source for env.

## Deliverables
- Enqueue helper using registry.enabled(env)
- Payload: searchId, userId, env, catalogId, category, subcategory, q/searchterms, source
- body.sources intersects enabled (cannot enable disabled); prefer 400 if only disabled listed

## Testable
- Mock SQS: N calls for N enabled sources
- Disabled never called
- sources:["amazon"] → only amazon
