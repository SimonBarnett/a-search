# FR-033: Default S3 PutObject in writeResults

## Goal
Workers can write results with only `S3_RESULTS_BUCKET` (+ AWS creds) set;
injected `putObject` remains for tests.

## Deliverables
- Default S3 client PutObject in `worker/lib/writeResults.js` when `putObject`
  omitted and bucket set
- `@aws-sdk/client-s3` dependency
- Document env in worker / provider `.env.example` files that write results

## Testable
- `tests/write-results-s3.test.js`: mock S3 client receives Bucket/Key/Body at
  canonical `{env}/{source}/{userId}/{catalogId}/{searchId}.json`
- Existing inject-based `write-results.test.js` still passes
- Fail-when: omitting putObject always throws even with bucket + mockable client hook

## Out of scope
- rclone mount on SQL host (docs already in FR-029)
