# FR-153: API Gateway CORS allowlist (configurable origins)

**Repo:** SimonBarnett/a-search
**Phase:** 3b - AWS installable gap pass 2
**Shape:** service (unchanged)

## Goal
HttpApi currently has no CORS. Club Madeira / browser callers need an allowlist (origins from CDK context; default deny or localhost-only in synth fixtures).

## Deliverables
- CORS on HttpApi for /search, /selftest, /account/performance
- Context key for origins; pin test
- Note in docs/deploy.md

## Testable
- Synth + pin

## Out of scope
- `*` public wildcard in production

## Decision LOCKED

- Context key: `-c corsOrigins=origin1,origin2` (comma-separated).
- Default when unset: `http://localhost:3000` (synth / local fixtures).
- Empty `-c corsOrigins=` -> deny (omit corsPreflight / no origins).
- Reject any list entry `*` at resolve time (`A_SEARCH_CORS_WILDCARD`).
- Preflight allows GET, POST, OPTIONS; headers Authorization, Content-Type, Accept.
- Pin: `tests/fr153-api-cors-allowlist.test.js`. Deploy note: `docs/deploy.md` CORS section.
