# FR-237: Wix shop connect via Wix app install (instanceId)

**Repo:** SimonBarnett/a-search
**Phase:** 5e - Merchant shops
**Issue:** #1351
**Status:** Decision LOCKED

## Goal
Merchant clicks Add shop -> Wix, installs the a-search Wix app. a-search stores
the app `instanceId` (vault pointer on the Shop row) and mints short-lived access
tokens for Wix Stores APIs. No pasted API keys.

## Auth model (confirmed)

Current Wix Apps use **Create Access Token** with `grant_type=client_credentials`,
`client_id` (app id), `client_secret`, and `instance_id`:

`POST https://www.wixapis.com/oauth2/token`

Access tokens last about 4 hours. They are **cached in memory only**
(`providers/local/wix/src/token.js`) and never written to the vault or logs.
Legacy custom-auth refresh tokens may still be stored when a callback supplies
them; new installs rely on instanceId minting.

External install URL:

`https://www.wix.com/installer/install?appId&redirectUrl&state`

Callback query includes `instanceId` + `signedInstance` (verify before trust).

## Decision (LOCKED)

- Adapter: `shared/shops/adapters/wix.js` registered as `wix`.
- `POST /merchant/shops/connect { provider:"wix" }` -> installer redirect + FR-216 nonce.
- `GET|POST /merchant/shops/callback/wix` verifies `signedInstance`, upserts Shop
  `pending_payment`, vault-puts `{ kind:"wix_instance", instanceId, ... }` at
  `vault:wix:{instanceId}` (no access token).
- Bad signedInstance / expired state => **400**, no Shop row.
- `POST /webhooks/shop/wix` (HMAC/JWT): App Removed => Shop `suspended`
  reason `uninstalled` + cancel subscription stub (FR-239).
- App id/secret: Secrets Manager `a-search/{env}/providers/wix/app`.
- Catalogue: `providers/local/wix/src/catalog.js` accepts per-call
  `{ siteId, accessToken }` overrides; env remains selftest fallback.
- madeiradb read-only (FR-251). Shops in a_search (FR-235).
