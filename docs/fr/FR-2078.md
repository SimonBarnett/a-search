# FR-2078: Chrome extension live identity + logged-in top bar

**Repo:** SimonBarnett/a-search
**Phase:** 5 - ComponentsPiece
**Issue:** #2078
**Status:** Decision LOCKED

## Goal
Wire live `chrome.identity.launchWebAuthFlow` against the shared login stack (FR-229) and the logged-in top bar actions left out of #1344 MVP: commission chip, Stripe link, Claim (club-only), Upgrade, Create widget (clipboard snippet), and Edit dialog (PATCH + feedback).

## Decision (LOCKED)

- Identity: `extension/background.js` calls `chrome.identity.launchWebAuthFlow` with
  `buildExtensionLoginUrl` -> `/components-piece/login/?extension=1&intent=&redirect_uri=`.
  Parse JWT from redirect `#access_token=` / `jwt=` via `parseJwtFromRedirectUrl`.
  Store JWT only in `chrome.storage.session`. Fixture JWT via `login` message `{ fixtureJwt }` for pins/UAT.
  Login page only redirects to `chrome-extension:` or `https://*.chromiumapp.org` (MRB #2224).
  Claim is gated in the service worker as well as the UI (`role === club`).
- Logged-in bar actions (Shadow DOM): commission chip (`GET /account/commission`),
  Stripe (`POST /account/stripe/link`), Claim club-only (`POST /account/payouts` when JWT role/intent is `club`),
  Upgrade (`POST /account/upgrade`), Create widget (`POST /widgets` + clipboardWrite snippet).
- Edit dialog: layout PATCH `/widgets/{guid}`; feedback POST `/widgets/{guid}/feedback`.
- Shared helpers: `shared/extension/webAuthFlow.js`, `shared/extension/barModel.js`.
- Pin: `tests/fr2078-chrome-identity-bar.test.js`.

## Testable

- URL builder + redirect JWT parse + club-only Claim gate
- Bar model action ids for logged-out / club / non-club
- Extension sources: launchWebAuthFlow, data-action claim/create/upgrade/stripe, edit-dialog, no JWT sinks
- Login page documents extension redirect hash

## Out of scope

- FR-234 stats chip / Performance tab
- Live Stripe Connect account creation beyond existing stub URLs
- Durable Widgets SQL bind (FR-232 remainder)
