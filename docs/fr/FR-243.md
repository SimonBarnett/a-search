# FR-243: Magento / Adobe Commerce Integration OAuth 1.0a shop connect

**Repo:** SimonBarnett/a-search
**Phase:** 5e - Merchant shops
**Issue:** #1357
**Status:** Decision LOCKED

## Goal

Connect a self-hosted Magento 2.4.x / Adobe Commerce store via Integration
OAuth 1.0a, vault four credentials, and let FR-240 import catalogue into
`a_search.dbo.Parts`. Merchant source.

## Decision (LOCKED)

Simon 14:11 / 15:27 BST (issue updates win).

- Do **not** require `oauth/consumer/enable_integration_as_bearer`. Sign every
  request OAuth 1.0a **HMAC-SHA256** with consumer key/secret + access token/secret.
- Adapter: `shared/shops/adapters/magento.js`. Activation POST to
  `/merchant/shops/callback/magento` holds consumer creds 10 minutes.
  Identity: `/merchant/shops/magento/identity?state=` binds merchant nonce then
  exchanges request/access tokens; verifies `GET /rest/V1/store/storeConfigs`.
- `store_base_url` HTTPS public only (SSRF gate, same as FR-238). Unknown
  consumer key / expired activation / http|private IP -> 400, no outbound call
  for SSRF rejects.
- Provider `providers/local/magento/` stay-dark. Catalogue pageSize 100.
  Configurable products: **parent with min price** (skillbook documents choice).
- 401 during sync -> Shop `suspended(auth)` + reconnect notice stub. No uninstall webhook.
- madeiradb read-only (FR-251).
