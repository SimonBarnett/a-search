## Goal
Land the deploy wiring left out of FR-240 product tip #2137: FIFO queue,
DLQ, and Lambda event source for shop catalogue sync.

## Decision (LOCKED)

- Queue: `a-search-shop-sync.fifo` (stage suffix inserted before `.fifo`).
- DLQ: `a-search-shop-sync-dlq.fifo`, `maxReceiveCount: 5` (FR-240).
- `fifo: true`, `contentBasedDeduplication: false` (explicit MessageDeduplicationId).
- Consumer: `maintainer/src/shopSyncWorker.handler` on maintainer Lambda asset;
  timeout 300s; queue `visibilityTimeout` = 6x timeout; `SqsEventSource` batchSize 1.
- Env `SQS_SHOP_SYNC_URL` on entry + maintainer live/sandbox; grantSendMessages to those.
- FR-239 `onShopLive` enqueue remains the live-transition caller (FR-239 still open);
  this tip only provisions the queue + consumer.
- MRB #2227: handler is `(event, context, deps)` like maintainer schedule; without
  injectable deps it throws `shop_sync_deps_unconfigured` (fail closed - no empty-registry
  ack/delete). Deploy must inject MSSQL/vault shops before the consumer is useful.
- Pin: `tests/fr2139-shop-sync-fifo-cdk.test.js`.
