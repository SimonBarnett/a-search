# FR-219: Widget copy page on smartcatalogue.uk mode plus embed

**Repo:** SimonBarnett/a-search
**Phase:** 5 - ComponentsPiece
**Shape:** service (unchanged; wizard/pages are delivery)
**Issue:** #1224

## Goal
Page on smartcatalogue.uk: select horizontal/vertical/fullscreen and copy embed
snippet with no hardcoded host. Each copy mints a new widgetGuid via POST
/widgets (FR-232 rule 2/4).

## Decision (LOCKED)

- Copy page: `components-piece/widget-copy/index.html` (served / linked from
  smartcatalogue.uk). Mode radios: horizontal | vertical | fullscreen.
- On Copy, the page calls `POST /widgets` with
  `{ "layout", "createdVia": "smartcatalogue" }` (anonymous OK; no host).
  Response 201 `{ widgetGuid, layout, snippet }`. Each copy = a new widget.
- Snippet shape (FR-232 rule 4):
  `<div class="a-search-widget" data-widget-guid="{guid}" data-mode="{layout}"></div>`
  plus `<script src="{WIDGET_JS_URL}" async></script>`. No host in the snippet;
  widget self-configures from `location.host` at runtime.
- Fullscreen may be selected; show notice: "Full catalogue needs Upgrade
  (GBP 10/month) for the site; until then shows the top 10" (#1345). Not a hard
  block (host unknown at copy time).
- `WIDGET_JS_URL` from env `A_SEARCH_WIDGET_JS_URL` (default
  `https://cdn.smartcatalogue.uk/a-search-widget.js`).
- In-memory Widgets registry for mint; durable SQL / bind is FR-232 / FR-196.
- Out of scope: clubmadeira.uk duplicate (FR-220), DNS TXT writer.

## Deliverables
- Copy-page HTML
- POST /widgets mint + CDK route
- Mode + data-widget-guid in snippet; partner mock updated

## Testable
- Snippet contains data-mode and data-widget-guid; no shop.example host
- Two copies -> two different GUIDs
- mocks partner home shows guid+mode shape

## Out of scope
- clubmadeira.uk duplicate (FR-220)
- DNS TXT writer
- Full Widgets bind / Parts host mismatch (FR-232 remainder)
