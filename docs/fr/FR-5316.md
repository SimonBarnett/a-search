# FR #5316

GitHub: https://github.com/SimonBarnett/a-search/issues/5316

## Goal

Agent `POST /search` (body has hostkey, guid, and queries) returns the skip list the fan-out already computes.

## Deliverables

- The 202 body includes `skipped` as an array of `{ id, reason }`.
- Reasons already produced stay the wire values: missing queue URL, `affiliates_enabled_0`, `affiliates_folder_missing`, `affiliates_s3_error`, `invalid_provider_slug`.
- `sql` stays queued. `queued` is unchanged.

## Testable

- A fixture where one provider is `affiliates_enabled_0` and one queue URL is missing asserts both objects on the HTTP body, not only on the helper return.
- Idempotent 202 still includes `skipped` (empty when nothing was skipped).
