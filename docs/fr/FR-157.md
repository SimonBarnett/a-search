# FR-157: API Gateway access logging + basic throttle settings

**Repo:** SimonBarnett/a-search
**Phase:** 3b - AWS installable gap pass 2
**Shape:** service (unchanged)

## Goal
Enable HTTP API access logs to CloudWatch and set conservative default route throttling (context-overridable) so abuse does not melt worker queues.

## Deliverables
- Access log group + stage access log settings
- Throttle burst/rate via context defaults
- Pin/synth

## Testable
- Synth + pin

## Out of scope
- WAF WebACL (separate if needed later)

## Decision LOCKED

- `HttpApi` with `createDefaultStage: false` + explicit `HttpStage` `$default`
- Access logs: `LogGroupLogDestination` on `HttpApiAccessLogGroup` (30d, RETAIN); CLF format
- Throttle: `resolve-api-throttle.js` - defaults rate 20 / burst 40; `-c apiThrottleRate=` / `-c apiThrottleBurst=`
- Pin: `tests/fr157-api-access-logs-throttle.test.js`
- Deploy note: `docs/deploy.md` API access logs + throttle
