# FR-037: Package Lambda assets so entry sees providers/

## Goal
Entry Lambda deployment package must include `providers/registry.json`,
`loadRegistry.js`, `queueName.js`, and enqueue deps — `Code.fromAsset(entry/src)`
alone cannot resolve `../../providers/...` at runtime.

## Deliverables
- Packaging script or CDK asset root (e.g. bundle via esbuild, or asset at
  repo root with handler path) documented in `cdk/README.md`
- Entry runtime can `require` registry helpers inside Lambda
- No secrets in the asset

## Testable
- Unit or synth+path test: packaged asset listing includes `providers/registry.json`
- Smoke: load registry from packaged layout in test harness
- Fail-when: CDK still points only at `entry/src` with relative requires outside asset

## Out of scope
- Provider worker packaging (can share pattern; separate if large)
