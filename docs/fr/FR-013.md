# FR-013: Conditional feed download skip on 304 or matching ContentHash

## Goal
Avoid blind CSV download when unchanged.

## Deliverables
- If-None-Match / If-Modified-Since; 304 → skip
- Matching ContentHash after download → skip upsert; bump LastChecked

## Testable
- Mock 304 → no upsert
- Hash match → no upsert
