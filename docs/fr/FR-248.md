# FR-248: Outbound links carry affiliate id + tenantId; merchants unstamped

**Repo:** SimonBarnett/a-search
**Phase:** 5 - ComponentsPiece / provider hardening
**Issue:** #1362
**Status:** Decision LOCKED

## Goal

Stamp outbound links with our network affiliate id and a tenantId reporting
slot for AFFILIATE and PROVIDER sources. MERCHANT sources return the plain
product URL. Widget `/go` stamps at click time (clubId); API path stamps at
result-write time (JWT userId).

## Decision (LOCKED)

Simon 14:23 / 14:35-14:49 / 15:00 / 15:27 BST (issue updates win).

- Taxonomy: every `providers/registry.json` entry has
  `class: affiliate|merchant|provider`. `kind: live` -> provider; merchants
  have `merchantConnect: true`.
- Builder: `shared/links/networkParams.js` + `buildOutboundUrl(source, opts)`.
  `buildTrackedUrl` accepts `source` and delegates. Fail closed when affiliate
  id or tenantId missing for affiliate/provider. Merchant -> URL unchanged.
- Bug fixes: Impact campaign is path (not `subId1`); Rakuten publisher is
  query `id` (not `mid`); CJ website id is path PID (`sid` is tenant).
- partnerId slots filled only when `isPartner(user)` -
  `Users.permissions` contains `'partner'` (not `Users.role`).
- Amazon: upgraded clubs (active `widget_upgrade`) may use
  `{store}-{lower(tenantId)}-21` when provisioned in `AmazonTrackingIds`;
  else base `AMAZON_PARTNER_TAG` + log `amazon_tag_missing`. Alert at
  `AMAZON_TAG_ALERT_AT` (default 50).
- Remove Wix/WooCommerce `*_AFFILIATE_ID` sid stamping.
- madeiradb read-only (FR-251). `AmazonTrackingIds` in `a_search`.
