# FR-173: Enable provider webgains (stay-dark -> registry enabled)

**Repo:** SimonBarnett/a-search
**Phase:** 4 - post-v0.1 enablement / hardiness
**Issue:** #1020
**Status:** Decision LOCKED

## Goal

Flip only `webgains` `enabled.live` / `enabled.sandbox` to true after
credentials exist in Secrets Manager, following `docs/phase3-enable-provider.md`
(FR-126). CDK synthesises queues/workers for this id. Sibling stay-dark ids
remain false unless their own enable FR already merged.

## Decision (LOCKED)

- Registry: `webgains.enabled.live` and `enabled.sandbox` = true.
- FR-138 secret wiring: `PROVIDER_CREDENTIAL_KEYS.webgains` lists
  `WEBGAINS_API_KEY`, `WEBGAINS_API_TOKEN`, `WEBGAINS_FEED_TOKEN`,
  `WEBGAINS_PUBLISHER_ID`, `WEBGAINS_CAMPAIGN_ID` (Secrets Manager JSON per env).
- Synth: `a-search-webgains-{live,sandbox}` queues +
  `a-search-webgains-worker-{live,sandbox}` Lambdas with secret refs.
- Do not enable admitad / flexoffers / wix / woocommerce in this FR.
- Selftest: existing `webgainsSelftestProbe` (FR-087) remains the probe path.
