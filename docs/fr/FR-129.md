# FR-129: CDK: create S3 results bucket + outputs (no IAM yet)

**Repo:** SimonBarnett/a-search  
**Phase:** 3 - AWS installable release  
**Shape:** service (unchanged)

## Goal
Add an S3 bucket (or confirm one-bucket-prefix scheme from FR-124) to `ASearchStack` with CfnOutputs for bucket name/ARN. Do not invent production account IDs. No public ACL.

## Decision (LOCKED)

One dedicated `ResultsBucket` in `cdk/lib/a-search-stack.js` (FR-124 one-bucket
`live/` + `sandbox/` key prefixes). CDK auto-names the bucket (no hard-coded
production name/account). `BlockPublicAccess.BLOCK_ALL` + S3-managed encryption
+ `RemovalPolicy.RETAIN`. Outputs: `ResultsBucketName`, `ResultsBucketArn`.
IAM / Lambda env = FR-130.

## Deliverables
- Bucket construct in `cdk/lib/a-search-stack.js`
- Outputs `ResultsBucketName` / `ResultsBucketArn`
- Synth pin test
