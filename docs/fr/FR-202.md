# FR-202: Widget inherit host CSS no competing theme

**Repo:** SimonBarnett/a-search
**Phase:** 5 - ComponentsPiece
**Shape:** service (unchanged)
**Issue:** #1190

## Goal
Widget CSS is layout-only; no brand color/font theme that fights the host.

## Decision (LOCKED)

- Canonical sheet: `widget/a-search-widget.css` (layout only).
- Theme ownership: host page sets `color`, `font-family`, and `background*`; widget uses `inherit`, `currentColor`, `transparent`, or `none` only for those properties.
- Modes (`horizontal` | `vertical` | `fullscreen`) change flex direction / wrap / sizing only.
- Mocks under `docs/mocks/components-piece/` keep a host theme in their own `<style>` and link the layout sheet.
- Pin: `tests/components-piece-widget-css.test.js` forbids banned theme props in the widget sheet and checks mocks stay host-themed.

## Deliverables
- Layout stylesheet audit (`widget/a-search-widget.css`)
- Pin forbidding theme color/font rules in widget CSS

## Testable
- Pin scans widget CSS for banned theme properties
- mocks remain host-themed

## Out of scope
- Parts API
- Click `/go` wiring (FR-203)
