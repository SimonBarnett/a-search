# FR-215: Merchant signup wizard select catalogue provider

**Repo:** SimonBarnett/a-search
**Phase:** 5 - ComponentsPiece
**Shape:** service (unchanged; wizard/pages are delivery)
**Issue:** #1220
**Status:** Implemented picker module + page (OAuth/Stripe out of scope)

## Goal

Wizard / **Add shop** UI step lists MERCHANT catalogue platforms; selection is
required before Connect. Picker is reused for every Add shop (many shops per
merchant, FR-235).

## Deliverables

- [x] Page: `components-piece/merchant-wizard/index.html`
- [x] Module: `shared/merchantWizard.js` -- list from registry `merchantConnect`
  plus locked MERCHANT plan
- [x] Enum (no prestashop): `shopify | wix | woocommerce | squarespace | magento |
  bigcommerce | ecwid`
- [x] Registry: `shopify` / `wix` / `woocommerce` carry `class: merchant` +
  `merchantConnect: true` (wix/woocommerce stay disabled = coming soon until
  their enable FR)
- [x] Mocks: `docs/mocks/components-piece-merchant/home.html`
- [x] Tests: `tests/components-piece-merchant-wizard.test.js`

## Behaviour

- Build options from `merchantConnect: true` / MERCHANT plan so new platforms are
  config + adapter.
- Connect-enabled only when registry flags `merchantConnect` and env `enabled`.
- Disabled / planned options show **coming soon** + interest capture (not an error).
- Cannot advance to Connect without a selection; cannot Connect on coming-soon ids.
- PrestaShop **dropped**; eBay/Etsy are PROVIDERs (not in picker).

## Out of scope

- OAuth token exchange (FR-216+)
- Stripe (FR-239)
