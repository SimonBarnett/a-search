# FR #5319

GitHub: https://github.com/SimonBarnett/a-search/issues/5319

## Goal

When the Etsy worker gets one product, it writes exactly one IN file for that search.

## Deliverables

- Worker pin: inject the Etsy search function to return one product.
- No live Etsy call.

## Testable

- `/IN/` put count is 1 and the key ends with `-etsy.json`.
- `_search-done/{searchid}/etsy.json` is serviced with products 1.
- The existing zero-product Etsy case still writes no IN file.
