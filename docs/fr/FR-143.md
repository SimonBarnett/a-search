# FR-143: CloudWatch log retention + DLQ depth alarm for entry/workers

**Repo:** SimonBarnett/a-search  
**Phase:** 3 - AWS installable release  
**Shape:** service (unchanged)

## Goal
Set log retention (e.g. 30 days) on Lambdas and a CloudWatch alarm when any worker DLQ has visible messages > 0.

## Decision (LOCKED)

- Every Lambda gets an explicit `logs.LogGroup` with `retention: RetentionDays.ONE_MONTH` (30 days) via `logGroup` (not deprecated `logRetention`)
- Placeholder SNS topic `a-search-ops-alarms` (output `OpsAlarmTopicArn`); no PagerDuty/webhook subscriptions
- Per enabled worker DLQ: CloudWatch alarm `a-search-{id}-{env}-dlq-depth` on `ApproximateNumberOfMessagesVisible >= 1` with `SnsAction` to the placeholder topic
- Depends on FR-142 sibling DLQs (`{queueName}-dlq`)
- Pin: `tests/fr143-cw-retention-dlq-alarm.test.js`

## Deliverables
- Retention + alarm(s) in CDK
- Pin/synth

## Testable
- Synth + pin

## Out of scope
- PagerDuty/SNS subscription targets beyond a placeholder topic
