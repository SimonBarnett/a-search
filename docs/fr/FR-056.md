# FR-056: CDK schedules for local onboarding drain runners

## Goal
Wire EventBridge schedules for each enabled local onboarding drain Lambda
(live + sandbox), mirroring clubscan `Awin-Onboarding` cadence intent.

## Deliverables
- CDK: onboarding Lambda(s) per source or one orchestrator with source param
- Separate live/sandbox env stamps (`A_SEARCH_ENV`)
- Schedule rate/cron documented (default proposal daily + optional frequent drain)
- IAM: only needed SQS/S3/Secrets; no provider secret echo in templates
- Outputs: function names + rule names

## Testable
- `npm run synth` + test asserting rule targets onboarding handlers
- Fail-when: only search/maintainer schedules exist

## Out of scope
- Club-specific recommendation emails (clubscan `club` route)
