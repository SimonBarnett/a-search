# FR-218: Partner registration sends DNS partner code plus instructions

**Repo:** SimonBarnett/a-search
**Phase:** 5 - ComponentsPiece
**Shape:** service (unchanged; wizard/pages are delivery)
**Issue:** #1223

## Goal
Partner registration widget/flow issues partner code for DNS and sends/shows
instructions pointing at smartcatalogue.uk (and mentions the Chrome extension).

## Decision (LOCKED)

- `POST /partner/register` (public; optional `email` in JSON body) mints an
  8-character partner code matching `^[0-9A-Z]{8}$` (docs/identity.md /
  shared/identity/userId.js). Production injects `dbo.GenerateUniqueUserId` (or
  equivalent); checksum is not re-implemented in a-search.
- Response includes `partnerCode`, `instructionsUrl`
  (`https://smartcatalogue.uk/partners`), and `instructions` text that
  references smartcatalogue.uk, Partner TXT DNS, and the Chrome extension gate
  (`GET /ext/status`, FR-200 cache / #1344).
- Registration UI: `components-piece/partner-register/index.html` (also linked
  from smartcatalogue.uk / clubmadeira.uk). Widget mode picker / copy embed body
  is out of scope (CP15).
- No change to code format or delivery shape after the 2026-10-10 direction
  note; Partner TXT also enables the extension on that host.
- Out of scope: Stripe Connect, widget mode picker page body.

## Deliverables
- Mint/send partner code (8-char identity shape)
- Instructions URL smartcatalogue.uk (+ extension mention)
- Registration UI + API + CDK route

## Testable
- Response partner code matches `^[0-9A-Z]{8}$`
- Instructions reference smartcatalogue.uk and the extension

## Out of scope
- Widget mode picker page body
- Stripe Connect
