- FR-122 **Chosen option** may stay PENDING until ops stamps A/B/C; FR-149 still documents the no-VPC + A allowlist playbook so installable deploy is not blocked on VPC IaC.
- Options B (VPN) and C (on-box only) remain in `docs/environments.md` Network path (FR-122); no CDK VPN/VPC constructs in this FR.
- **Never** invent private IPs, firewall dumps, or VPN secrets in git.
