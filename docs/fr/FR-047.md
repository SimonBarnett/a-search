# FR-047: Shared layer for shared a-search code

## Goal
Shared deterministic helpers must live in one shared layer/package — not
duplicated under providers. Match clubscan layer-first pattern.

## Deliverables
- Repo folder `shared/` (Node package) containing at least:
  - results path + writeResults + assertEnv (move from `worker/lib/` or re-export)
  - product normalize helper (align FR-042)
  - intake exception reporter stub interface (wired in FR-048)
- Document Lambda layer publish path `/opt/nodejs/a-search` (or CDK
  `NodejsFunction` bundling shared) in `docs/shared-layer.md`
- Update imports in entry/worker/providers; delete duplicate copies
- CDK/README note: layer or bundle includes `shared/`

## Testable
- Pin test: no second copy of `resultsKey` / `writeResults` under `providers/`
- Unit tests still pass via `shared/` requires
- Fail-when: providers ship forked resultsPath.js

## Out of scope
- Publishing to public npm; Grok/mailer layers from AWS monorepo
