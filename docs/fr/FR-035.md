# FR-035: CDK API Gateway POST /search to entry

## Goal
Synth'd stack exposes HTTP `POST /search` to the entry Lambda matching vision
architecture (API Gateway to entry).

## Deliverables
- API Gateway REST or HTTP API in `cdk/lib/a-search-stack.js`
- Route `POST /search` to entry Lambda; grant invoke
- Outputs: API URL
- Test asserting synth template contains the route + integration

## Testable
- `npm run synth` succeeds
- `tests/cdk-apigw.test.js` finds API resource and POST /search to entry
- Fail-when: stack only has naked Lambda with no API surface

## Out of scope
- Custom domain / JWT authorizer at API GW (entry still verifies Bearer)
- Multi-account deploy
