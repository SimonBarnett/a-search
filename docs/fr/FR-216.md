# FR-216: Merchant shop connection via platform logged-in session

**Repo:** SimonBarnett/a-search
**Phase:** 5 - ComponentsPiece
**Shape:** service (unchanged; wizard/pages are delivery)
**Issue:** #1221

## Goal
After provider select, use logged-in session on that platform to return shop
connection details; prompt login if not signed in. Orchestrates many shops per
merchant (connect handoff + callback), then redirects to subscribe (FR-239).

## Decision (LOCKED)

- `POST /merchant/shops/connect { provider, shopDomain? }` (JWT merchant) stores
  a `state` nonce (10 min, bound to merchantUserId + env) and returns the
  provider `redirectUrl`. "Prompt login if not signed in" happens at the
  provider login/consent page (fixture adapter exposes `loginRequired`).
- `GET|POST /merchant/shops/callback/{provider}` consumes the nonce, delegates
  to the provider adapter, persists a **Shops** row (status `pending_payment`)
  with a credentials vault pointer only. Do **not** persist shop credentials on
  the merchant/customer record.
- Adapter interface (`shared/shops/adapters/{provider}.js`):
  `startConnect(ctx) -> { redirectUrl, loginRequired? }`,
  `completeConnect(req, nonce) -> { providerShopId, shopDomain, displayName,
  scopes, credentials }`, `verifyWebhook(req)`, `revoke(credentials)`.
- Prefer OAuth / app-install over pasted API keys. Credentials are never
  returned to the browser or logged. FR-216 ships a `fixture` adapter for
  tests; Shopify / Wix / Woo live adapters are FR-236 / FR-237 / FR-238.
- After a successful callback, redirect to the smartcatalogue.uk wizard
  "Subscribe this shop" step (FR-239) via `A_SEARCH_SUBSCRIBE_URL`.
- Shops table lives in the a-search database (`a_search` / `a_search_sandbox`),
  migration `db/migrations/010_Shops.sql` (FR-251). madeiradb is read-only.
  Full status machine + encrypted vault wiring is FR-235; this FR owns connect
  orchestration + pending_payment insert.
- Two different shops of the same provider by one merchant => two Shop rows.
- Out of scope: Stripe payment (FR-239), widget copy page, production deploy.
