# FR-038: Amazon SQS Lambda handler wrapping run(msg)

## Goal
Amazon worker is invokable from SQS: parse record body → `run(msg)` → succeed
or throw for retry; wire as CDK handler for amazon queues.

## Deliverables
- `providers/live/amazon/src/handler.js` (or `index.handler`) mapping
  `event.Records[]` JSON bodies to `run`
- Env isolation via existing `assertWorkerEnv`
- Document in amazon skillbook
- CDK worker uses this handler (depends on FR-036 or land stub handler first)

## Testable
- `tests/amazon-handler.test.js`: one SQS record → run called; bad JSON → throw;
  wrong-env msg → EnvIsolationError
- Fail-when: only `run(msg)` export exists with no Lambda entrypoint

## Out of scope
- Changing PA-API SearchItems behaviour (FR-030 done; Creators = FR-045)
