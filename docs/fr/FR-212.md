# FR-212: JSON contract fixtures in.json live.json searches.json

**Repo:** SimonBarnett/a-search
**Phase:** 5 - ComponentsPiece
**Shape:** service (unchanged)
**Issue:** #1200

## Goal

Checked-in fixtures + schema pins for in/live/searches (and GUID-tree / events / stats) shapes used by agent and Parts API.

## Decision (LOCKED)

- Fixtures live under `tests/fixtures/components-piece/`.
- `in.json` item: `{ id, title, price, currency, merchant, image, url, seenAt }`.
- `live.json` item: in fields + `partNumber`, `score`, `expiresAt`, `source`, `class` (`affiliate|merchant|provider`), `shopId` when merchant; `url` is clean destination (no affiliate network params).
- Fixtures: `live.free.json` length exactly `LIVE_PART_CAP_FREE` (10); `live.full.json` length > 10.
- `searches.json`: `{ queries: [{ q, intent, maxResults }], exclude: [...] }`.
- `widget.json`: `{ widgetGuid, host, customerNumber, layout, createdVia, createdAt }` with layout in `horizontal|vertical|fullscreen`.
- `feedback.json` entries: `context` or `remove`; remove reasons enum from #1344.
- `_host.json`: `{ host, customerNumber, createdAt }`.
- SQS job (`sqs.job.json`): `{ eventType, env, customerNumber, widgetGuid|null, host, s3Key|null, at }`.
- `widgetGuid` matches FR-232 regex `^[0-9a-f]{8}-[0-9a-f]{4}-[45][0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$`.
- Events / stats fixtures per FR-234; ctr = 0 when denominator is 0; ctr rounded to 4 dp; no PII keys (`ip`, `ua`, `userId`, `email`, ...).
- Reject secret-like keys on every fixture document.
