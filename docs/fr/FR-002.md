# FR-002: Add providers/registry.json with all shortlist sources and per-env enabled

## Goal
Machine-readable registry of every shortlist source.

## Deliverables
- `providers/registry.json` matching docs/provider-shortlist.md
- Each source: `id`, `kind` (live|local), `folder`, `enabled` as `{ "live": bool, "sandbox": bool }`
- Defaults ON both envs: amazon, ebay, awin, rakuten, cj, impact; others OFF
- Loader `providers/loadRegistry.js` exporting `enabled(env)`

## Testable
- Unit test: `enabled('live')` returns exactly the default-on ids
- Unit test: a default-off id is absent from `enabled('sandbox')`
