# FR-245: BigCommerce shop connect via single-click app OAuth

**Repo:** SimonBarnett/a-search
**Phase:** 5e - Merchant shops
**Issue:** #1359
**Status:** Decision LOCKED

## Goal

Install the a-search BigCommerce app on a merchant store via single-click OAuth,
vault the non-expiring store API token, and let FR-240 import catalogue into
`a_search.dbo.Parts`. Merchant source. Source key `bigcommerce` reused by name only.

## Decision (LOCKED)

Simon 14:35-14:49 / 15:27 BST (issue updates win).

- Auth: BigCommerce app OAuth. Auth callback
  `{api}/merchant/shops/callback/bigcommerce`. Load + Uninstall callbacks use
  `signed_payload_jwt` HS256 with client secret; verify `aud`/`sub`.
- Token exchange `POST https://login.bigcommerce.com/oauth2/token` yields a
  **non-expiring** `access_token` + `context=stores/{store_hash}`.
- Adapter: `shared/shops/adapters/bigcommerce.js`. Uninstall ->
  `suspended(uninstalled)` + cancel subscription stub (FR-239).
- **No migrate-legacy-bigcommerce** (Simon: no live BC accounts in madeiradb).
- Provider `providers/local/bigcommerce/` stay-dark until app creds exist.
  Catalogue: `GET .../v3/catalog/products` limit 250; honour rate-limit headers / 429.
  Parts: `Source=bigcommerce`, `FeedKey=shopId`, `MerchantProductId=product id`.
- madeiradb read-only (FR-251). All SQL in `a_search` / `a_search_sandbox`.
