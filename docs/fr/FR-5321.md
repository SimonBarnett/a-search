# FR #5321

GitHub: https://github.com/SimonBarnett/a-search/issues/5321

## Goal

`docs/phase4-enablement-index.md` names every registry id that is enabled on live and sandbox as already enabled, and the skimlinks row kind matches the registry (`local`).

## Deliverables

- Extend the "Already enabled" sentence to include kelkoo, skimlinks, etsy, partnerize, webgains, tradedoubler, shopify, wix, and woocommerce, plus the phase-1 ids already listed.
- Set the skimlinks table kind to `local`.
- Hold ids stay hold: bol, aliexpress, avantlink, flexoffers, admitad.
- Update `tests/fr166-phase4-enablement-index.test.js` only if it must assert the new sentence.
- Do not change `providers/registry.json`.

## Testable

- A pin reads `providers/registry.json` and asserts each id with `enabled.live` and `enabled.sandbox` true appears in the already-enabled sentence.
- Hold ids are still described as hold. `fr166` stay-dark asserts for admitad and flexoffers still pass.
