# FR-251: a-search owns a_search / a_search_sandbox; madeiradb is read-only

**Repo:** SimonBarnett/a-search
**Issue:** #1365
**Status:** Decision LOCKED
**Priority:** HIGHEST

## Goal

All a-search tables, migrations and writes live in **`a_search`** (live) and
**`a_search_sandbox`** (sandbox) on the same MSSQL instance as madeiradb.
a-search **never writes madeiradb** (no DML/DDL). Identity is read-only via
schema **`mdb`**.

## Decision (LOCKED)

Simon 2026-10-10 15:27 / 15:38:

1. Same MSSQL server as madeiradb; databases `a_search` / `a_search_sandbox`.
2. Copy existing Parts/PartFeedKeys from madeiradb if present; leave madeiradb
   copies untouched (no DROP/DELETE by a-search).
3. Merchants live only in `a_search.dbo.Merchants` (not madeiradb Users).
4. Sandbox identity is an anonymised `mdb.*` copy inside `a_search_sandbox`
   (no madeiradb access for the sandbox app login).
