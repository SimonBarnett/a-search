# FR #5320

GitHub: https://github.com/SimonBarnett/a-search/issues/5320

## Goal

When the Kelkoo worker gets one offer, it writes exactly one IN file for that search.

## Deliverables

- Worker pin with an injected search that returns one offer. No Publisher Center values and no `.env` file.
- Do not change the synth soft-disable that omits `SQS_KELKOO_*` when `providers/live/kelkoo/.env` is missing.

## Testable

- `/IN/` put count is 1 and the key ends with `-kelkoo.json`.
- `_search-done/{searchid}/kelkoo.json` is serviced with products 1.
- The existing zero-product Kelkoo case still writes no IN file.

Refs #5058. Does not close #5058.
